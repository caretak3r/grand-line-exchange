# Grand Line Exchange

A Bloomberg-Terminal-styled trading dashboard for One Piece TCG *sealed
booster boxes* — 22 tracked English sets (OP-01…OP-15, EB, PRB), live
prices, 30-day momentum, RSI, buy/sell signals, a live sales tape, and an
equal-weight market index.

{/* This site documents the dashboard; it does not host it. */}

## The one idea everything follows from

**There is no backend. The repo is the database.** A GitHub Action runs the
scraper hourly and commits fresh JSON to `public/data/`. A static
Vite/React build on GitHub Pages fetches those files at load. No servers,
no API keys required, free to run forever.
